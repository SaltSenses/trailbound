# Trailbound Live 0.9.0

Install `trailbound-live-v0.9.0.apk` once. The new icon is **Trailbound Live**, package `ca.trailbound.app.live`. It installs alongside earlier Trailbound previews. **Keep the old app installed** and export its native tracks and Settings backup, then import copies into Live. Separate Android packages have separate storage; installation does not migrate data automatically.

Open Live online. It checks for the latest published app screens, features and bundled trail data, downloads and verifies the complete release, and refreshes when ready. Settings → App updates shows progress and offers Check for updates now. Downloads are about 10 MB for the current release. An active native recording delays activation until Finish. Existing data in Live stays on the device through web-content updates. If offline or a download fails, the working version remains available. A startup health check restores the previous version if new JavaScript cannot initialize.

Includes the 243-section community-mapped Trans Canada Trail collection, regional offline maps and corrected native recorder. TCT coverage is incomplete; water, ferry and explicitly foot-restricted sections are view/export only. Offline basemaps remain regional.

Automatic updates apply to published web features and bundled data. They do not verify live trail closures, download every Canadian trail, or change native Android permissions/code. Native changes still require a new APK. Permanent release signing and Play Store distribution remain unconfigured; this is a debug preview. No subscription or API key is required.

Source and deployment: https://github.com/SaltSenses/trailbound
