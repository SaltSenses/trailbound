# Trailbound Android 0.8.0 preview

243 community-mapped Trans Canada Trail sections are bundled for offline browsing, route loading and GPX export. Open Explore routes → Browse Trans Canada Trail, or Live map → Trans Canada Trail. National map lines and numbered clusters show the mapped sections. Water, ferry and explicitly foot-restricted sections are view/export only.

This is incomplete OpenStreetMap coverage, not the official complete TCT inventory. Northwest Territories and Nunavut are absent from this snapshot. Road connections may be included. Check access, closures and continuity before hiking. National offline terrain basemaps are not included; offline basemaps remain regional.

Install `trailbound-android-v0.8.0-tct-preview.apk` on your Pixel. It appears as **Trailbound Preview 0.8** and uses `ca.trailbound.app.preview`, so the earlier Trailbound installation and its recordings remain separate. Do not uninstall the old app. Export its native tracks and Settings backup first; import those files into the new app if you want copies there. The preview starts with separate storage.

This build also includes the corrected native-only Android recorder, GPS metrics, status-bar spacing and duplicate-start protection. It uses a debug signing key. Permanent release signing and automatic native APK updates are still pending; web-app updates do not replace installed native code or bundled assets.
